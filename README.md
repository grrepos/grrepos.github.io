# Ganesh Rajamani — Portfolio

A responsive, single-page portfolio site built as a static website. The page includes an introduction, profile portrait, current agentic engineering and automation work, five personal project summaries, a role-by-role career timeline, education, and an expanded certifications section.

## Publish

This folder is ready to publish with any static-site host. For example, on Netlify or Cloudflare Pages, create a new site and set the publish directory to this folder; no build command is needed. For GitHub Pages, upload these files to a repository and enable Pages from the repository's main branch.

## Before publishing

Review the wording and dates for the credentials, especially the items marked Oct 2026. Update any credential date or title if your public credential page changes. The profile image is stored beside `index.html` as `ganesh-rajamani.jpg`; keep both files together when uploading. Project summaries describe the current repositories; only Shadow Echo has a live demo link in its README. Private repository URLs and configuration details are intentionally not exposed on the public portfolio. Add a custom domain in your chosen host's site settings if desired.
