# Ganesh Rajamani — Portfolio

A responsive, single-page portfolio site built as a static website. The page includes an introduction, selected leadership experience, education, and an expanded certifications section reflecting the recent badges shown in the supplied LinkedIn certification-page capture.

## Publish

This folder is ready to publish with any static-site host. For example, on Netlify or Cloudflare Pages, create a new site and set the publish directory to this folder; no build command is needed. For GitHub Pages, upload these files to a repository and enable Pages from the repository's main branch.

## Before publishing

Review the wording and the dates for the credentials, especially the items marked Oct 2026. Update any credential date or title if your public credential page changes. Add a custom domain in your chosen host's site settings if desired.
